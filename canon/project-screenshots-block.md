## Каталог screenshots/

Каталог `screenshots/` — временный обмен файлами с оператором. Оператор кладёт
туда файлы с хоста через смонтированный диск; для тебя они появляются как
обычные локальные файлы.

- Ссылаться на файл: `@screenshots/имя.png` или абсолютным путём.
- Не коммитить: каталог исключён из git намеренно.
- Не удалять и не чистить без явной просьбы: файл может понадобиться позже.
- Если оператор говорит «посмотри скриншот» без имени — проверить каталог
  на самый свежий файл и уточнить, тот ли это.
